java.net.NetworkInterface

java.net.NetworkInterface 는 호스트의 네트워크 인터페이스(이더넷 카드, 무선 어댑터, 루프백 등) 하나를 표현하는 클래스이다.[1] 인터페이스마다 이름과 그에 묶인 IP 주소들이 있고, 활성 여부나 멀티캐스트 지원 여부 같은 속성을 질의할 수 있다.

java.net.NetworkInterface
package java.net;

public final class NetworkInterface {

    public static Stream<NetworkInterface> networkInterfaces() throws SocketException {...} (1)

    public String getName() {...}                                                           (2)
    public String getDisplayName() {...}

    public Stream<InetAddress> inetAddresses() {...}                                        (3)

    public boolean isUp() throws SocketException {...}                                      (4)
    public boolean isLoopback() throws SocketException {...}
    public boolean supportsMulticast() throws SocketException {...}                         (5)

    ...
}
1 호스트의 모든 네트워크 인터페이스를 Stream 으로 나열하는 정적 팩토리 메서드이다.
2 운영체제가 붙인 인터페이스 이름(en0, eth0 등)을 돌려준다. getDisplayName() 은 사람이 읽기 좋은 설명을 돌려주며, 플랫폼에 따라 이름과 같을 수도 있다.
3 이 인터페이스에 묶인 IP 주소들을 Stream<InetAddress> 로 돌려준다. Inet4Address 인지 Inet6Address 인지로 IPv4 / IPv6 지원 여부를 가린다.
4 인터페이스가 활성 상태인지 돌려준다. isLoopback() 은 루프백 인터페이스인지를 가린다.
5 인터페이스가 멀티캐스트를 지원하는지 돌려준다.

NetworkInterfacesViewer

멀티캐스트처럼 인터페이스를 직접 골라야 할 때는 먼저 이 호스트에 어떤 네트워크 인터페이스가 있는지 살펴보는 것이 편하다. NetworkInterfacesViewer 는 이 호스트의 모든 네트워크 인터페이스를 트리로 펼쳐, 각 인터페이스의 속성을 이름·값·형 세 열로 보여 주는 작은 Swing 프로그램이다.

Figure 1. NetworkInterfacesViewer 실행 화면

up, loopback, inetAddresses 같은 속성을 보면 어느 인터페이스가 활성인지, 루프백인지, 어떤 IP 주소를 갖는지 한눈에 알 수 있다. GUI 없이 같은 내용을 콘솔로 출력하는 NetworkInterfacesPrinter 도 함께 들어 있다. 두 프로그램 모두 01-verbose-hello-world-api 모듈의 테스트 소스 (src/test/java) 아래 com.github.jinahya.hello.util 패키지에 있으며, 각자의 main 메서드로 실행한다.

java.net.SocketOption<T>

java.net.SocketOption<T> 는 소켓 옵션 하나를 표현하는 인터페이스이다.[2] 옵션의 이름과 값의 형만 가질 뿐, 실제 값은 소켓·채널 쪽에서 읽고 쓴다.

java.net.SocketOption
package java.net;

public interface SocketOption<T> {

    String name();

    Class<T> type();
}

name() 은 옵션의 이름을, type() 은 옵션 값의 형을 돌려준다. 타입 매개변수 T 가 그 형이며, SO_RCVBUF 는 Integer, TCP_NODELAY 는 Boolean 처럼 옵션마다 정해져 있다.

소켓과 채널은 getOption(SocketOption<T>) 으로 옵션 값을 읽고, setOption(SocketOption<T>, T) 으로 값을 지정하며, supportedOptions() 으로 지원하는 옵션 집합을 알려 준다. 지원하지 않는 옵션을 읽거나 쓰려 하면 UnsupportedOperationException 이 난다. 예컨대 데이터그램 소켓에서는 송신 버퍼의 크기가 보낼 수 있는 데이터그램의 크기를 제한할 수 있으므로, 필요하면 getOption(StandardSocketOptions.SO_SNDBUF) 로 그 값을 확인해 본다. 버퍼보다 큰 데이터그램을 보내거나 버리는 동작은 시스템마다 다르다.

java.net.StandardSocketOptions

java.net.StandardSocketOptions 는 표준 소켓 옵션들을 SocketOption 상수로 모아 둔 클래스이다.[3]

java.net.StandardSocketOptions
package java.net;

public final class StandardSocketOptions {

    public static final SocketOption<Boolean> SO_BROADCAST = ...;
    public static final SocketOption<Boolean> SO_KEEPALIVE = ...;
    public static final SocketOption<Integer> SO_SNDBUF = ...;
    public static final SocketOption<Integer> SO_RCVBUF = ...;
    public static final SocketOption<Boolean> SO_REUSEADDR = ...;
    public static final SocketOption<Boolean> SO_REUSEPORT = ...;
    public static final SocketOption<Integer> SO_LINGER = ...;
    public static final SocketOption<Integer> IP_TOS = ...;
    public static final SocketOption<NetworkInterface> IP_MULTICAST_IF = ...;
    public static final SocketOption<Integer> IP_MULTICAST_TTL = ...;
    public static final SocketOption<Boolean> IP_MULTICAST_LOOP = ...;
    public static final SocketOption<Boolean> TCP_NODELAY = ...;
}
옵션 값의 형 의미

SO_BROADCAST

Boolean

브로드캐스트 데이터그램 전송을 허용한다.

SO_KEEPALIVE

Boolean

연결 유지(keep-alive) 신호를 켠다.

SO_SNDBUF

Integer

송신 버퍼 크기.

SO_RCVBUF

Integer

수신 버퍼 크기.

SO_REUSEADDR

Boolean

주소 재사용을 허용한다.

SO_REUSEPORT

Boolean

포트 재사용을 허용한다.

SO_LINGER

Integer

close() 가 미전송 데이터를 마저 보낼 때까지 기다리는 시간(초).

IP_TOS

Integer

IP 헤더의 서비스 형(ToS) 값.

IP_MULTICAST_IF

NetworkInterface

멀티캐스트 송신에 쓸 인터페이스.

IP_MULTICAST_TTL

Integer

멀티캐스트 패킷의 TTL.

IP_MULTICAST_LOOP

Boolean

멀티캐스트 루프백 사용 여부.

TCP_NODELAY

Boolean

Nagle 알고리즘을 끈다.

SocketOptionsViewer

소켓 종류마다 지원하는 옵션과 그 기본값이 다르다. SocketOptionsViewer 는 여덟 가지 소켓·채널 형(Socket, ServerSocket, SocketChannel, ServerSocketChannel, AsynchronousSocketChannel, AsynchronousServerSocketChannel, DatagramSocket, DatagramChannel)이 어떤 표준 옵션을 지원하고 그 기본값이 무엇인지 한 표로 보여 주는 작은 Swing 프로그램이다.

Figure 2. SocketOptionsViewer 실행 화면

지원하지 않는 옵션은 NOT SUPPORTED 로 회색 표시된다. GUI 없이 같은 내용을 콘솔로 출력하는 SocketOptionsPrinter 도 함께 들어 있다. 두 프로그램 모두 01-verbose-hello-world-api 모듈의 테스트 소스 (src/test/java) 아래 com.github.jinahya.hello.util 패키지에 있으며, 각자의 main 메서드로 실행한다.
