= IEEE 754 constants — C vs. Java

This file maps C's floating-point-related constants (from `<float.h>`, `<math.h>`, and
`<fenv.h>`) to their nearest Java counterparts (mostly `java.lang.Float` / `java.lang.Double`,
plus `java.math.RoundingMode` for the rounding modes).

Cells are left empty where no counterpart exists on that side. C values shown are the typical
IEEE 754 `binary32` / `binary64` values; some C macros (`FLT_ROUNDS`, `FLT_EVAL_METHOD`,
`DECIMAL_DIG`, the `<fenv.h>` bit masks, the `FP_*` / `math_errhandling` codes) are
implementation-defined and shown as such.

[CAUTION]
====
Two mappings are *not* one-to-one:

* `MIN_VALUE` mismatch — C `DBL_MIN` is the smallest *normal* value (≙ Java `MIN_NORMAL`),
  whereas Java `MIN_VALUE` is the smallest *subnormal* value (≙ C `DBL_TRUE_MIN`).
* Exponent off-by-one — C `*_MAX_EXP` / `*_MIN_EXP` and Java `MAX_EXPONENT` / `MIN_EXPONENT`
  use different conventions and differ by 1 (e.g. `DBL_MAX_EXP` = 1024 vs.
  `Double.MAX_EXPONENT` = 1023).
====
